Privacy Policy

Last updated: 16 August 2026. এই policy static demo site-এর current behaviour explain করে। Production launch-এ analytics, forms বা database যোগ করলে policy update করুন।

1. Information you provide

Live Chat বা support interaction ব্যবহার করলে আপনি message text, Agent ID বা listing reference voluntarily দিতে পারেন। Static demo version নিজে থেকে server database-এ support message save করে না; WhatsApp button ব্যবহার করলে message third-party WhatsApp service-এ যাবে।

2. Search information

Current front-end search browser-এর মধ্যে sample directory data filter করে। Search query server-এ store করার backend এই static version-এ নেই। Production analytics বা search logging যোগ করলে সেটা policy-তে disclose করা উচিত।

3. Local storage and browser data

Current version UI functionality-এর জন্য প্রয়োজনীয় browser features ব্যবহার করতে পারে। Future version theme preference, consent বা session information local storage/cookie-তে রাখলে purpose এবং retention clearly disclose করুন।

4. Third-party services

WhatsApp বা অন্য external link click করলে আপনি third-party service-এ চলে যাবেন। তাদের privacy practices আমাদের control-এর বাইরে; ব্যবহার করার আগে তাদের policy review করুন।

5. What we do not ask for

Directory verification-এর জন্য password, OTP, PIN, recovery code বা full payment credential share করা উচিত নয়। Support channel-এ এই ধরনের তথ্য পাঠাবেন না।

6. Data retention

Static version server-side support record রাখে না। Production backend যোগ করলে support request কতদিন রাখা হবে, কেন রাখা হবে এবং কখন delete করা হবে—স্পষ্ট retention rule publish করুন।

7. Security

Reasonable technical controls ব্যবহার করা উচিত, তবে কোনো web service absolute security guarantee করতে পারে না। Sensitive information যত কম collect করা যায় তত ভালো।

8. Children

এই directory child-focused service নয়। Production business model অনুযায়ী minimum age requirement applicable হলে Terms ও Privacy Policy-তে স্পষ্ট করুন।

9. Policy changes

Material privacy practice change হলে policy update করুন এবং meaningful last-updated date দিন। শুধু freshness দেখানোর জন্য date পরিবর্তন করবেন না।

10. Contact

Privacy question-এর জন্য production launch-এর আগে একটি real privacy email যোগ করুন: privacy@yourdomain.com.
