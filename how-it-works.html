Simple process

Three steps. No extra layers.

The interface keeps discovery and verification separate so the user always knows what to do next.

1

Search

Use a profile ID, name or area from the home screen or directory page.

2

Review

Check the visible role, area, status and profile ID before taking any next step.

3

Confirm

Use the support page if you need a current confirmation or want to report a listing.

Keep the live version equally simple

Connect search to your real backend, publish a clear verification standard, replace all sample contacts, and keep mobile tap targets large. Avoid decorative effects that compete with the main actions.
