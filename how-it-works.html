Agent verification guide

Agent খুঁজে Profile ID কীভাবে verify করবেন

Directory record ব্যবহার করার সবচেয়ে ভালো উপায় হলো কয়েকটি field একসাথে মিলিয়ে দেখা। শুধু name বা WhatsApp number দেখে profile confirm করবেন না।

Step 1: সঠিক role page বেছে নিন

প্রথমে বুঝুন আপনি Master Agent, Super Agent নাকি Admin listing খুঁজছেন। তিনটি category আলাদা page-এ রাখার কারণ হলো search result ছোট রাখা এবং role confusion কমানো।

Master Agent ListSuper Agent ListAdmin List

Step 2: Name-এর চেয়ে Agent ID-কে বেশি গুরুত্ব দিন

একই বা কাছাকাছি নাম একাধিক মানুষের হতে পারে। তাই search result-এ exact Agent ID পাওয়া গেলে সেটাকে primary reference হিসেবে ব্যবহার করুন। Name, ID এবং role—এই তিনটি একই record-এর সাথে মিলছে কি না দেখুন।

Step 3: Area ও listing status check করুন

Profile record-এ area এবং status দেখানো থাকলে সেগুলোও match করুন। Available মানে directory-তে profileটি currently active হিসেবে দেখানো হচ্ছে; Limited মানে contact বা availability নিয়ে restriction থাকতে পারে। Exact status definition Verification Policy-তে রাখা হয়েছে।

Step 4: Listed contact compare করুন

আপনার কাছে যে phone বা messaging contact এসেছে, সেটা directory-র listed number-এর সাথে compare করুন। Mismatch হলে কারণ না জেনে sensitive information বা credential share করবেন না।

Step 5: Support confirmation নিন

কোনো field mismatch হলে Customer Service-এ Agent ID উল্লেখ করুন। Verification request-এ password, OTP, PIN বা financial credential দেওয়া উচিত নয়।

Step 6: Wrong information report করুন

Phone, ID, role, status বা profile name ভুল দেখলে Report a Listing page ব্যবহার করুন। Clear report directory accuracy improve করতে সাহায্য করে।

What verification means

Directory verification কী নিশ্চিত করে—আর কী করে না

Verification-এর scope

  • Profile ID directory record-এর সাথে match করছে কি না
  • Role, area ও listed contact record-এর সাথে consistent কি না
  • Listing status current record অনুযায়ী কী
  • Reported correction বা change review করা হয়েছে কি না

Verification যা guarantee করে না

  • কোনো ব্যক্তির সব online identity genuine—এমন blanket guarantee
  • Third-party message বা unlisted phone number automatically safe
  • Future behaviour বা service outcome
  • Directory-র বাইরে করা private agreement

Common mistakes

Verification-এর সময় ৫টি common mistake

1. Exact ID না দেখা

Name match হলেই একই profile ধরে নেওয়া।

2. Screenshot-কে final proof ধরা

Old screenshot outdated হতে পারে; live directory recheck করুন।

3. Unlisted number-এ reply

Listed contact-এর সাথে compare না করে conversation continue করা।

4. Secret তথ্য share

OTP, PIN, password বা recovery code দেওয়া।

5. Wrong listing report না করা

Mismatch দেখেও correction request না পাঠানো।
