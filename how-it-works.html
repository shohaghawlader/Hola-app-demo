How it works

Simple directory lookup এবং reporting process।

1. Directory খুলুন

Master, Super অথবা Admin list থেকে প্রয়োজনীয় category খুলুন।

2. ID দিয়ে search করুন

Search box-এ profile ID দিলে দ্রুত exact result পাবেন। Name বা area দিয়েও filter করা যায়।

3. Verify করুন

Verify button support form-এ profile ID পাঠায়। Production backend যুক্ত হলে support team current listing details confirm করতে পারবে।

4. ভুল তথ্য report করুন

Report button issue form prefill করে। Listing data change হলে পুরনো information সরাতে এই workflow ব্যবহার করা যাবে।
