Report an Agent Listing

Wrong phone, incorrect Agent ID, duplicate profile, wrong role/area বা outdated status দেখলে report করুন। Clear report directory accuracy maintain করতে সাহায্য করে।

কোন issue report করবেন?

  • Listed phone number ভুল বা outdated
  • Agent ID ভুল, duplicate বা mismatched
  • Role category ভুল
  • Area information ভুল
  • Status outdated
  • Duplicate profile
  • Profile removal/correction request

Report-এ কী information দিন?

  • Exact Agent ID
  • Profile name
  • Problem type
  • Correct information, যদি জানা থাকে
  • Relevant non-sensitive screenshot বা URL reference

Do not include: password, OTP, PIN, recovery code বা private financial credential.

Quick report route

Static HTML version-এ backend form save হবে না। নিচের button Customer Service খুলবে; production-এ WordPress/backend connect করলে report records database-এ save করা যাবে।

একটি report-এর পরে ideal review flow

01

Reference check

Agent ID এবং current listing locate করা।

02

Evidence review

Reported issue ও available record compare করা।

03

Correction

Confirmed change হলে listing update, limit বা remove করা।

Important: এই page directory correction-এর জন্য। Immediate danger, fraud loss বা legal emergency-এর ক্ষেত্রে appropriate local authority/qualified professional-এর assistance প্রয়োজন হতে পারে.
