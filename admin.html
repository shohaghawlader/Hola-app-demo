Admin List কী?

Admin listing directory-level support বা escalation context বোঝাতে ব্যবহার করা হয়। Admin label কোনো unlimited authority বা personal guarantee বোঝায় না; support policy অনুযায়ী scope define করা উচিত।

এই page-এর মূল উদ্দেশ্য হলো একই category-র profileগুলোকে এক জায়গায় দেখানো, যাতে visitor নামের পাশাপাশি Agent ID, area, listed contact এবং status compare করতে পারে।

এই list কীভাবে ব্যবহার করবেন

  1. Profile name এবং Agent ID মিলিয়ে নিন।
  2. Area ও current listing status check করুন।
  3. Listed contact-এর বাইরে কোনো number পেলে compare করুন।
  4. Doubt থাকলে Customer Service-এ ID দিয়ে confirmation চান।

Contact করার আগে ৫টি detail check করুন

  • Agent ID: profile শনাক্ত করার primary reference.
  • Role: listingটি এই directory category-এর সাথে match করছে কি না.
  • Area: profile record-এ যে area দেখানো আছে সেটা expected context-এর সাথে মিলছে কি না.
  • Listed phone: অন্য জায়গা থেকে পাওয়া phone number-এর সাথে compare করুন.
  • Status: Available বা Limited label-এর current meaning Verification Policy-তে দেখুন.

Master & Super Agent Lists-এর সাথে পার্থক্য

Master/Super pages মূল profile categories দেখায়, আর Admin page directory-level record বা escalation context আলাদা করে। কোনো issue-এর ধরন অনুযায়ী relevant page ব্যবহার করুন।

Role label দেখে কোনো extra authority বা guarantee ধরে নেবেন না। Directory roleগুলো record grouping-এর জন্য ব্যবহার করা হচ্ছে।

Safety

Agent list ব্যবহার করার সময় যে ভুলগুলো এড়াবেন

01

শুধু নাম match করা

একই বা কাছাকাছি নাম থাকলে Agent ID ছাড়া profile confirm করবেন না।

02

Random phone বিশ্বাস করা

Search result, message বা social post থেকে পাওয়া number directory record-এর সাথে মিলান।

03

OTP/PIN share করা

Support verification-এর জন্য password, OTP, PIN বা secret credential দরকার হওয়া উচিত নয়।

04

Mismatch ignore করা

Wrong contact বা status দেখলে report করুন।

Admin List সম্পর্কে common questions

Agent ID কোথায় পাব?

প্রতিটি card-এর ডান দিকে বা profile information-এর মধ্যে Agent ID দেখানো আছে।

Listing status বদলাতে পারে?

হ্যাঁ। Directory record সময়ের সাথে update হতে পারে, তাই গুরুত্বপূর্ণ contact-এর আগে status recheck করুন।

Phone number mismatch হলে?

Listed number এবং received number আলাদা হলে support confirmation ছাড়া sensitive information share করবেন না।

Wrong profile report করব কোথায়?

Report a Listing page-এ Agent IDসহ details দিন।
