ⓘ কিভাবে ডিরেক্টরি ব্যবহার করবেন:

DemoWin একটি sample agent-directory website। Agent-এর নাম, Agent ID, area এবং listed contact একইসাথে মিলিয়ে নিন। কোনো profile “Listed” থাকলেই তার সব দাবি স্বয়ংক্রিয়ভাবে সত্য প্রমাণিত হয় না। সন্দেহ হলে support page ব্যবহার করুন।

How to verify a listed agent?

Use the directory to check an Agent ID, role and listed contact before starting a conversation. If a phone number or profile detail does not match the directory, do not share sensitive information. Use the report or customer-service page for clarification.
