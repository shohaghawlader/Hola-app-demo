About the directory

DemoWin Agent List কী এবং এই site কীভাবে ব্যবহার করবেন?

এই site-এর কাজ হলো directory information গুছিয়ে দেখানো—যাতে visitor কোনো নাম বা contact দেখেই তাড়াহুড়া না করে, বরং profile record মিলিয়ে তারপর সিদ্ধান্ত নিতে পারে।

এক জায়গায় তিন ধরনের listing

Master Agent List, Super Agent List এবং Admin List আলাদা page-এ রাখা হয়েছে। এতে role বুঝে relevant list খুলতে সুবিধা হয় এবং একই ধরনের profile একসাথে compare করা যায়।

প্রতিটি listing-এ অন্তত Agent ID, role, area, status এবং listed contact রাখার লক্ষ্য। এই তথ্যগুলোর যেকোনোটি mismatch হলে listing report করা উচিত।

“Listed” মানে কী?

Listed badge শুধু বোঝায় যে profileটি directory record-এর অংশ। এটি কোনো ব্যক্তির পরিচয়, আর্থিক সক্ষমতা বা অন্য কোনো দাবি সম্পর্কে blanket guarantee নয়। Verification-এর scope জানতে Verification Policy পড়ুন।

Contact করার আগে Agent ID এবং listed contact মিলিয়ে নেওয়া সবচেয়ে গুরুত্বপূর্ণ step.
