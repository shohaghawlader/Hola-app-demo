Agent Verification Policy

এই policy explain করে directory-তে “Listed”, “Available”, “Limited” এবং correction status কীভাবে ব্যবহার করা উচিত। Production launch-এর আগে আপনার actual verification workflow অনুযায়ী policy final করুন।

1. Listing-এর minimum information

একটি profile directory-তে publish করার আগে minimumভাবে একটি unique Agent ID, display name, role category এবং current listed contact থাকা উচিত। Area বা availability information publish করলে সেটার source ও update processও consistent হওয়া দরকার।

2. “Listed” badge-এর অর্থ

Listed মানে profileটি directory record-এর অংশ এবং publish করার সময় required fields পূরণ করেছে। এটি কোনো ব্যক্তির সব claim, financial status, future conduct বা third-party promise guarantee করে না।

3. Status definitions

AvailableCurrent directory record-এ profile active/contactable হিসেবে দেখানো হচ্ছে।
LimitedAvailability বা contact-এর ওপর restriction/uncertainty থাকতে পারে; support confirmation recommended.
Under ReviewListing-এর কোনো detail review চলছে; final confirmation না পাওয়া পর্যন্ত caution প্রয়োজন.
RemovedProfile আর active directory listing হিসেবে দেখানো হবে না।

4. Verification checks

  • Agent ID duplicate কি না
  • Name ও role supplied record-এর সাথে consistent কি না
  • Listed contact expected record-এর সাথে match করে কি না
  • Area/status information publish করার মতো current কি না
  • Previous correction বা report unresolved আছে কি না

5. Review and update

Material change—যেমন phone, role, status বা identity reference change—হলে listing update করা উচিত। Review date meaningful update বা actual review ছাড়া পরিবর্তন করা উচিত নয়।

6. Correction process

Wrong listing report এলে Agent ID, issue description এবং available non-sensitive evidence review করুন। Confirmed correction হলে page update করুন এবং internal record-এ change note রাখুন।

7. Removal

Duplicate, materially inaccurate, unresolved identity mismatch বা policy violation থাকলে listing temporary hide বা remove করার rule define করুন।

8. No blanket guarantee

Directory verification record matching-এর জন্য। এটি directory-র বাইরে private conversation, third-party link, unlisted number বা future outcome-এর guarantee নয়।

Listing নিয়ে সমস্যা পেয়েছেন?

Agent ID, issue type এবং correct informationসহ report পাঠান। Sensitive credential পাঠাবেন না।
