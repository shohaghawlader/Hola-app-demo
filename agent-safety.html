Safety guide

Agent-এর সাথে যোগাযোগের আগে কীভাবে check করবেন

Directory record helpful reference, কিন্তু safe decision-এর জন্য কয়েকটি simple check একসাথে করা ভালো। এই guideটি suspicious contact এবং listing mismatch চিনতে সাহায্য করবে।

প্রথমে exact Agent ID দেখুন

Name familiar লাগলেও exact ID ছাড়া profile confirm করবেন না। Search overlay-তে ID লিখে matching role ও contact দেখুন।

Listed phone number compare করুন

Message, social profile বা forwarded screenshot থেকে পাওয়া phone number directory-তে থাকা number-এর সাথে মিলছে কি না দেখুন। Mismatch হলে আগে কারণ clear করুন।

Role ও area match করুন

একজন profile Master, Super নাকি Admin হিসেবে listed—এটা record-এর সাথে মিলিয়ে দেখুন। একইভাবে area field থাকলে সেটা context-এর সাথে consistent কি না দেখুন।

Secret credential কখনো share করবেন না

Directory verification বা listing correction-এর জন্য password, OTP, PIN, recovery code, full payment credential বা login secret প্রয়োজন হওয়া উচিত নয়। কেউ চাইলে conversation stop করে trusted support route ব্যবহার করুন।

Urgency pressure-এ সতর্ক থাকুন

“এখনই করতে হবে”, “ID check করার দরকার নেই” বা “নতুন number-এ reply করুন”—এ ধরনের pressure থাকলে extra verification করুন।

Red flags

Suspicious contact-এর ৮টি signal

01

Agent ID দিতে চায় না বা ID বারবার বদলায়

02

Directory-listed phone-এর বদলে সম্পূর্ণ অন্য number ব্যবহার করে

03

OTP, PIN, password বা recovery code চায়

04

Profile role বা area directory record-এর সাথে match করে না

05

Support verification এড়াতে চাপ দেয়

06

Old screenshot-কে একমাত্র proof হিসেবে দেখায়

07

Wrong information report না করতে বলে

08

Unlisted external link-এ sensitive action করতে বলে

!

Mismatch দেখলে কী করবেন

Conversation continue করার আগে record recheck করুন এবং official support path ব্যবহার করুন।

1
Agent ID copy করুন

Report-এর primary reference হিসেবে exact ID রাখুন।

2
Listed contact screenshot নিন

Sensitive data ছাড়া relevant detail save করুন।

3
Customer Service-এ check করুন

Mismatch explain করে confirmation চান।

4
Report করুন

Directory record ভুল হলে correction request পাঠান।
