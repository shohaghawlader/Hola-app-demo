AgentBase — Clean Neutral Full-Site Demo
========================================

What changed in this version
- The entire website now uses one consistent mobile-first design system.
- Warm off-white background, white surfaces, charcoal text and a muted sage accent.
- No gradients, neon colors, cursor effects, chart libraries, sliders or heavy animation.
- Compact sticky header and simple mobile bottom navigation on every page.
- Home keeps the main actions visible in a compact view: search, directories, verify, support and FAQ.
- Master / Super / Sub Admin pages use the same clean filters and card structure.
- How It Works, FAQ, Support, Privacy and Terms use the same spacing, typography and surface styling.
- External avatar/image requests were removed; profile initials are generated locally.
- Only two active JS files remain: agents.js (sample data) and site.js (UI behavior).

Before a real launch
1. Replace AgentBase, yourdomain.com, support email and phone placeholders.
2. Replace sample profile data in assets/js/agents.js with your real lawful directory data/backend.
3. Connect the support form to your own backend, email service or CRM.
4. Update sitemap.xml and robots.txt with the real domain.
5. Have the final privacy/terms copy reviewed for the actual service and jurisdiction.

Design direction
The UI intentionally avoids bright or decorative colors. The goal is calm, readable, low-clutter mobile use with important actions easy to find.
