Agent List FAQ

Agent search, Agent ID, role, listing status, verification এবং report process নিয়ে common questions-এর clear answer.

এটি Master Agent, Super Agent এবং Admin category অনুযায়ী profile record সাজানো একটি searchable directory. Visitor name, Agent ID বা listed phone দিয়ে record খুঁজে details compare করতে পারে।
Header-এর Search button খুলে exact Agent ID লিখুন। Matching record থাকলে result-এ নাম, role, phone এবং relevant directory page দেখাবে।
Name-এর পাশাপাশি Agent ID, role, area এবং listed phone number মিলিয়ে দেখুন। Unique Agent ID-কে primary reference হিসেবে ব্যবহার করুন।
এগুলো আলাদা directory categories। Exact authority বা service scope live policy অনুযায়ী define করা উচিত; শুধু label দেখে extra guarantee ধরে নেবেন না।
Directory-level record, correction বা escalation context বোঝার জন্য Admin List useful হতে পারে।
এটি বোঝায় profileটি directory record-এর অংশ। এটি ব্যক্তির সব claim বা future outcome-এর guarantee নয়।
Available মানে current directory record-এ active হিসেবে দেখানো হচ্ছে। Limited মানে availability বা contact-এ restriction থাকতে পারে। Exact definition Verification Policy-তে দেখুন।
Unlisted number-এ sensitive information না দিয়ে Customer Service-এ Agent IDসহ confirmation চান।
Report a Listing page-এ Profile ID, problem type এবং supporting detail দিন।
Agent ID, listing URL, problem description এবং non-sensitive screenshot দেওয়া যেতে পারে। Password, PIN, OTP বা recovery code share করবেন না।
Spelling, Agent ID এবং phone format আবার check করুন। এরপর relevant role page browse করুন বা Customer Service-এ query পাঠান।
Production version-এ material change হলে listing update করা উচিত এবং policy page-এ review process publish করা উচিত। শুধু fresh দেখানোর জন্য date পরিবর্তন করা ঠিক নয়।
না। Directory record information organization-এর জন্য। Listing থাকা মানেই blanket endorsement নয়।
Privacy Policy page-এ search, support message, local storage ও third-party service ব্যবহারের details রাখা হয়েছে।

Question-এর answer না পেলে

Agent ID, profile name এবং আপনার exact question নিয়ে Customer Service page ব্যবহার করুন। Sensitive information share না করেও বেশিরভাগ listing check করা সম্ভব।
